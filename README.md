# Pizzéria Žaba, koncept webu

Statický web (HTML, CSS, JS bez build kroku) pre GitHub Pages.

- `index.html` slovenská verzia, `en/index.html` anglická verzia
- `assets/site.css` štýly
- Obrázky a video sú hostované na Higgsfield CDN (vygenerované v Higgsfielde).

Stránka má `noindex`, kým ju majiteľ neschváli. Po schválení zmaž v oboch `index.html` riadok
`<meta name="robots" content="noindex, nofollow">`.
